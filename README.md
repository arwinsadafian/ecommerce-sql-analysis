# E-commerce Order Analysis System

**Status:** Work in Progress 🚧

## Project Overview

SQL-based analysis of e-commerce operations to identify revenue trends, customer segments, and product performance for
business decision-making.

## Business Context

This project simulates a realistic e-commerce database to demonstrate data analysis skills for business analyst roles.
Key questions answered include:

- What are our monthly revenue trends?
- Who are our most valuable customers?
- Which products should we discontinue?
- What's our return rate by category?

## Current Progress

- [x] Database schema design (5 normalized tables)
- [x] Sample data generation (500 customers, 100 products, 2000+ orders)
- [ ] Business analysis queries (in progress)
- [ ] Data visualization dashboard
- [ ] Documentation & insights

## Technical Stack

- **Database:** PostgreSQL 16
- **Data Generation:** Python (Faker, Pandas)
- **Tools:** DBeaver, Git
- **Skills:** SQL, database design, data modeling, Python

## Database Schema

5 normalized tables: customers, products, orders, order_items, returns
